# Security Policy

## Overview

Security is a foundational priority for **SGS Creations**. This repository serves as public architectural and technical documentation. The actual production application source code and deployment infrastructure are private.

## Supported Scope

Security updates, dependency audits, and hardening practices are continuously maintained for the production environment at:
- **Production URL**: [https://www.sgscreations.in](https://www.sgscreations.in)

## Reporting a Vulnerability

If you believe you have discovered a potential security vulnerability related to the SGS Creations platform, we appreciate your help in disclosing it responsibly.

### Responsible Disclosure Guidelines
* **Do NOT publicly disclose** vulnerability details, reproduction steps, or exploit methods in public issues, discussions, or social media.
* Provide sufficient information to reproduce and validate the issue.
* Do not attempt to access, alter, or destroy private user or system data.
* Allow reasonable time for investigation and remediation before any public disclosure.

### Contact
Please send vulnerability reports to the project maintainers through official contact channels listed on the [SGS Creations website](https://www.sgscreations.in).

Thank you for helping keep SGS Creations secure.
